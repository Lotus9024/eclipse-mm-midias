# EclipSe MM — Mídias

Links permanentes para usar em embeds do Discord, bots e sites.

Formato do link: `https://raw.githubusercontent.com/Lotus9024/eclipse-mm-midias/main/<pasta>/<arquivo>`

Pastas: `marca/`, `embeds/`, `posts/`, `motions/` e `emoji/`.

## marca

- `marca/logo-halloween.png` — logo de Halloween (avatar do bot)
- `marca/roblox-3d.png` — logo do Roblox em 3D (quadrado inclinado 15° com o furo), plástico roxo e rosa no ângulo dos ícones 3D do site; categoria "Roblox e itens virtuais" do middleman (512 px; `.blend` com o modelo)
- `marca/instagram-3d.png` — logo do Instagram em 3D (placa com o símbolo branco em relevo), mesmo estilo; categoria "Redes sociais ou servidores" do middleman (512 px; `.blend` com o modelo)

## emoji

Imagens de todos os emojis do servidor do Discord, com o mesmo nome do emoji (`emoji/<nome>.png`, ou `.gif` se for animado). O ID e o código de cada um ficam no Notion, em Time de Discord → Página Inicial de Servidor → Emojis existentes. Ao criar um emoji novo no servidor, adicione a imagem aqui e a linha lá.
